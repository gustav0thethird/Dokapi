# Output

Dokapi generates output in two primary formats: live console feedback and optional CSV reports.

## Console Feedback

When running Dokapi, users receive real-time feedback directly in the terminal. The output is colorized for clarity, allowing users to easily distinguish between different types of information. Key features of the console output include:

- **Live Updates**: As scans progress, results are displayed immediately, providing users with ongoing insights into the reconnaissance process.
- **Color Indicators**: Different colors are used to signify various statuses, such as successful scans, errors, or warnings, enhancing the readability of the output.

### Example Console Output

During a typical reconnaissance session, the console might display output similar to the following:

```text
Enter target URL or IP: example.com
Use Tor proxy? (y/n): y

[+] Starting API Hunt...
  - /api/status
  - /v1/users
  - /admin/panel

[+] Starting Port Scan...
  - 80 open
  - 443 open
```

This example illustrates how the tool communicates the progress of API hunting and port scanning, listing discovered endpoints and open ports.

## CSV Report Generation

In addition to console output, Dokapi offers the option to generate CSV reports for offline analysis. This feature is particularly useful for users who wish to maintain records of their reconnaissance activities or share findings with others.

### CSV Output Features

- **Automatic Filename Generation**: CSV files are named systematically based on the target and scan type, ensuring that reports are organized and easy to identify.
- **Storage Location**: Reports are saved in the `/Reports/` directory, which is automatically created if it does not exist.
- **Data Structure**: The CSV files contain structured data that can be easily imported into spreadsheet applications for further analysis.

### Example CSV Output

A typical CSV report generated by Dokapi might include columns for the target, scan type, and discovered endpoints or open ports, formatted as follows:

```csv
Target,Scan Type,Result
example.com,API Hunt,/api/status
example.com,API Hunt,/v1/users
example.com,API Hunt,/admin/panel
example.com,Port Scan,80 open
example.com,Port Scan,443 open
```

This structured format allows users to quickly review and analyze the results of their reconnaissance efforts.

## Conclusion

Dokapi's output capabilities, including live console feedback and optional CSV report generation, provide users with valuable insights during reconnaissance activities. The combination of real-time updates and organized reporting enhances the overall utility of the tool for stealth audits and network research.

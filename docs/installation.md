# Installation

To install Dokapi and its dependencies, follow the guidelines below.

## Prerequisites

Ensure you have Python 3.6 or higher installed on your system. You can download it from the official [Python website](https://www.python.org/downloads/).

## Clone the Repository

Clone the Dokapi repository from GitHub:

```bash
git clone https://github.com/gustav0thethird/Dokapi.git
cd Dokapi
```

## Install Dependencies

Dokapi requires certain Python packages to function correctly. You can install these dependencies using `pip`. Run the following command in the terminal:

```bash
pip install -r requirements.txt
```

This command will install all the necessary packages listed in the `requirements.txt` file.

## Running Dokapi

After installing the dependencies, you can run Dokapi using the following command:

```bash
python dokapi.py
```

Alternatively, you can use the shell interface:

```bash
python dokapi_shell.py
```

## Windows Users

If you are using Windows, you can also run the provided batch file to launch Dokapi:

```bash
launch_dokapi.bat
```

## Additional Configuration

If you need to customize settings, you can modify the `settings.py` file according to your requirements.

## Troubleshooting

If you encounter any issues during installation or while running Dokapi, ensure that:

- You have the correct version of Python installed.
- All dependencies are installed without errors.
- You have the necessary permissions to execute scripts on your system.

For further assistance, refer to the [README.md](README.md) file or check the issues section of the GitHub repository.

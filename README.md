# 🐙 Dokapi – Tor-Native Recon Toolkit

A lightweight, privacy-aware reconnaissance tool for researchers, analysts, and OPSEC-conscious operators. Runs natively through Tor with modular scans and a clean CLI.

---

### 🔍 Highlights

- 🌐 **Tor-Native Networking**  
  Routes all traffic through Tor for anonymity and reduced footprint.

- 🧩 **Modular Recon Architecture**  
  Includes plug-and-play modules for:
  - Port scanning  
  - HTTP header grabbing  
  - Passive domain and IP recon  
  - Tor proxy utilities  

- 💻 **Interactive CLI Shell**  
  Custom shell for interactive use with built-in commands and feedback.

- 🛡️ **OPSEC-First Design**  
  Designed to avoid detection, tracking, and unnecessary exposure.

---

### 💡 Ideal For

- Dark web exploration  
- Red team recon  
- Stealthy surface audits  
- Privacy-focused developers and researchers
